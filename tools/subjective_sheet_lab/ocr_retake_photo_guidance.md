# OCR 재촬영 안내

목적: `retake_required`가 뜬 학생에게 어떤 사진을 다시 찍어야 하는지 짧고 명확하게 안내한다.

## 학생용 짧은 문구

사진이 흐리거나 답칸 일부가 어둡게 찍혀 인식이 불안정합니다. 종이를 평평하게 두고, 밝은 곳에서 그림자가 없게 다시 찍어주세요. 네 모서리 기준 마커와 20개 답칸이 모두 보이게 촬영해야 합니다.

## 왜 재촬영이 뜨는가

| 원인 | 화면 상태 | 조치 |
| --- | --- | --- |
| blur | 글자가 번져 보임 | 카메라를 고정하고 초점을 맞춘 뒤 촬영 |
| cutoff risk | 답칸 일부나 경계가 잘릴 위험 | 답안지 전체가 화면 안에 들어오게 촬영 |
| shadow | 손/휴대폰 그림자가 답칸 위에 있음 | 빛을 정면보다 옆에서 받게 조정 |
| marker fail | 검은 기준 마커가 잘 안 보임 | 네 모서리 마커가 모두 보이게 촬영 |
| low contrast | 연필 글씨가 흐림 | 진하게 쓰거나 밝은 환경에서 촬영 |

## q001/q003/q020 사례에서 확인한 점

- q001: 숫자는 4처럼 보이나 crop이 부드럽고 흐림.
- q003: n/3처럼 보이는 stroke가 낮은 선명도로 찍힘.
- q020: 16은 보이지만 오른쪽 경계와 그림자 때문에 cutoff risk가 있음.

현재 정책은 이 문항들을 자동 확정하지 않고 `retake_required` 또는 `review_required`로 보낸다. 이게 안전한 동작이다.

## 좋은 촬영 조건

- 책상 위에 답안지를 평평하게 둔다.
- 화면 안에 답안지 전체와 네 개 기준 마커가 들어오게 한다.
- 그림자 없이 밝은 곳에서 촬영한다.
- 카메라를 종이와 최대한 평행하게 둔다.
- 흔들림 없이 초점을 맞춘 뒤 촬영한다.
- 답칸 아래 선에 글씨가 붙지 않게 쓴다.

## 다시 찍어도 안 될 때

- OCR 확정 화면에서 확인 필요 문항만 직접 입력한다.
- `retake_required`가 남아 있으면 답칸 채우기를 막는 것이 정상이다.
- 수동 입력 fallback으로 `답 입력 열기`에서 20줄을 직접 입력할 수 있다.
