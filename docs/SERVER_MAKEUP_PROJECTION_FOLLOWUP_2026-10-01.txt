의미 변경을 보류한 기존 차이
A. 서버 payload slots는 1/2 정수만, 브라우저 parser는 문자열 label과 1/2/3을 허용한다.
B. 서버 date helper는 Python compact/week ISO를 허용하지만 impossible date를 제외한다.
   브라우저는 앞 10자리 YYYY-MM-DD 모양을 검사하며 impossible date도 문자열로 받는다.
C. 서버의 기존 normalizer는 unknown root/row/schedule 출력 필드를 투영에서 제외한다.
   입력 객체/unknown 값은 변경하지 않지만 저장 결과에서 unknown을 보존하는 규칙은 아니다.
   이번 이동은 이 결과와 revision을 바꾸지 않았다.
D. backend schedule alias는 truthy camel → snake 순서다.
   browser는 명시적 camel tombstone이 snake/note fallback보다 우선한다.
E. server ownedExtra는 기존 bool coercion을 유지하며 browser는 strict true다.
이 차이는 분리 전 소스와 literal oracle로 확인했다.
통일하거나 unknown 출력 보존을 확대하면 API normalization/revision/clear 의미가 바뀐다.
이번 pure extraction에 합치지 않았다. Hub가 의미 정본과 승인 결정에 따라 별도 가지로 판단해야 한다.
현재 브라우저 동작 변경이나 운영 데이터 일괄 재정규화는 제안 patch에 포함하지 않았다.
