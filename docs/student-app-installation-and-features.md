# 5A Math 학생 앱 설치 및 기능 안내

## 먼저 접속할 주소

- 사용자용: <https://app.5a-math.com/app>
- 개발/QA용: <https://dev-app.5a-math.com/app>

`dev-app`은 QA canary 계정만 사용할 수 있는 개발 환경입니다. 학생과 보호자는 사용자용 주소를 사용합니다. `/student-app.html`이나 오래된 개인 페이지 주소를 설치 시작점으로 사용하지 말고 `/app`에서 설치합니다.

## 설치 방법

### Android 휴대폰·태블릿 — Chrome

1. Chrome에서 `https://app.5a-math.com/app`을 엽니다.
2. 학생 계정으로 로그인합니다.
3. 주소창의 설치 아이콘 또는 우측 상단 `⋮` 메뉴에서 `앱 설치`나 `홈 화면에 추가`를 선택합니다.
4. 설치를 확인하고 홈 화면의 5A Math 아이콘으로 실행합니다.
5. 알림을 받으려면 앱 안의 알림 설정에서 권한을 허용합니다.

기기에 따라 메뉴 이름이 `앱 설치`, `홈 화면에 추가`, `Install app` 중 하나로 보일 수 있습니다. 설치 메뉴가 없으면 HTTPS 주소인지, Chrome 최신 버전인지 확인한 뒤 페이지를 새로고침합니다.

### iPhone·iPad — Safari

1. Safari에서 `https://app.5a-math.com/app`을 엽니다. iOS/iPadOS에서는 Chrome보다 Safari 설치 흐름을 사용합니다.
2. 로그인 후 공유 버튼을 누릅니다.
3. `홈 화면에 추가`를 선택하고 추가를 확인합니다.
4. 홈 화면 아이콘으로 다시 열어 독립 앱 화면으로 실행합니다.
5. 지원되는 iOS/iPadOS 버전에서만 알림 권한을 요청할 수 있습니다. 권한 요청이 보이지 않으면 Safari 탭이 아니라 홈 화면에서 설치된 앱을 실행했는지 확인합니다.

### Windows·macOS — Chrome 또는 Edge

1. `https://app.5a-math.com/app`을 엽니다.
2. 주소창의 설치 아이콘 또는 브라우저 메뉴의 `앱 설치`를 선택합니다.
3. 바탕화면·시작 메뉴·Dock 추가 여부를 선택합니다.

### 설치 후 업데이트

서비스 워커가 `/app` shell과 정적 파일을 관리합니다. 새 버전이 배포되면 앱을 완전히 닫았다가 다시 열고, 화면이 오래된 경우 브라우저에서 한 번 새로고침합니다. `/student-app.html`을 직접 열어 캐시 문제를 해결하려고 하지 않습니다.

## 로그인과 계정 상태

- 이름이 유일한 학생은 이름과 기본 활성화 비밀번호 `1234`로 최초 활성화를 시작할 수 있습니다.
- 같은 이름의 학생이 있으면 관리자에게 받은 6자리 일회용 인증코드를 입력합니다.
- 최초 활성화 또는 관리자가 지정한 상태에서는 새 자격 증명 설정 화면이 먼저 나타납니다.
- 로그인 후 세션은 보안 쿠키로 유지되므로 앱을 다시 열면 자동으로 세션을 확인합니다. 다른 사람과 기기를 공유하지 마세요.
- 로그아웃·커리큘럼 전환·세션 취소가 일어나면 이전 화면의 세션은 사용할 수 없고 다시 인증해야 합니다.

## 학생 앱 기능

### 개인 학습 화면

학생별 서버 bootstrap을 기준으로 오늘 학습 자료, 배정 영상, 복습 영상, 시험, 공지, 숙제를 표시합니다. 현재 로그인한 학생의 active SID만 사용하며 다른 학생의 SID를 URL에 넣어 자료를 조회할 수 없습니다.

### 진도 확인

영상 시청 완료와 수동 진도 상태를 개인 화면에서 확인할 수 있습니다. 대시보드 진도율·전체 커리큘럼 집계는 해당 환경의 dashboard 기능이 켜진 경우 제공됩니다. 서버에 없는 값을 화면에서 추정하지 않습니다.

### 수업 일정

환경에서 dashboard 기능이 활성화되면 정규 수업, 결석, 보강·추가 일정과 다음 일정을 개인 화면에 표시합니다. 결석·취소된 일정은 다음 수업으로 잘못 표시하지 않도록 구분합니다.

### 지정 숙제와 기한

환경에서 homework 기능이 활성화되면 학생에게 지정된 숙제, 상태, 마감일을 표시합니다. 마감일이 원본 데이터에 없는 과거 숙제에는 임의의 날짜를 만들지 않습니다.

### 게시판·공지·영상

- 학생에게 공개된 공지와 게시판 항목을 확인합니다.
- 읽음 확인, 답글, 설문이 필요한 공지는 기존 공지 흐름으로 처리합니다.
- 공지에 연결된 영상은 학원 네트워크 정책에 따라 재생할 수 있습니다.
- 외부 네트워크에서는 영상·시험·정답·민감 파일이 잠금 처리될 수 있습니다. 이는 오류가 아니라 보안 정책입니다.
- 공지 알림의 deep link를 열면 앱의 게시판 항목으로 이동합니다. 만료되었거나 권한이 없는 항목은 표시하지 않습니다.

### 푸시 알림

현재 공지 알림과 일반 알림 기반이 구현되어 있습니다. 일정·숙제·진도 알림은 reminders 기능과 알림 작업이 운영 환경에서 활성화된 경우에만 발송됩니다.

알림을 받으려면 다음 조건이 필요합니다.

- 설치된 PWA 또는 지원 브라우저
- OS와 브라우저의 알림 권한 허용
- 앱 안의 알림 설정에서 원하는 범주 활성화
- 기기의 방해금지·절전 정책이 사이트 알림을 차단하지 않음

알림에는 학생 이름, 비밀번호, 세션 토큰, 정답 URL 같은 민감 내용을 넣지 않고 앱 안의 안전한 화면으로 이동하는 링크만 포함합니다.

### 커리큘럼 전환과 기존 개인 페이지

학생에게 여러 커리큘럼이 연결된 경우 앱의 전환 흐름에서 현재 커리큘럼을 바꿀 수 있습니다. 전환 시 세션이 회전되고 새 학생 화면으로 다시 연결되므로 이전 커리큘럼 URL을 계속 사용하지 않습니다.

기존 개인 페이지의 영상·자료·시험·공지 기능은 학생 화면에서 계속 연결됩니다. 모바일 설치 shell과 기존 학습 화면은 서로 다른 역할을 가지며, 로그인 후에는 인증된 학생 화면으로 이동합니다.

## 웹앱의 한계와 수업 집중 기능

웹앱은 Android/iOS 운영체제의 다른 앱을 끄거나, 다른 앱의 알림을 차단하거나, 화면 위에 항상 표시되는 권한을 획득할 수 없습니다. 따라서 Instagram·KakaoTalk 같은 앱 전환 자체를 강제로 막는 기능은 제공하지 않습니다.

focus 기능이 운영 환경에서 별도로 켜진 경우에는 학생 페이지가 보이는지·숨겨졌는지 같은 coarse 상태만 수업 시간 범위 안에서 기록할 수 있습니다. 전화, 잠금, 권한창, 앱 전환을 구분할 수 없으므로 “앱 이탈 추정”으로만 해석합니다.

focus 기록에는 URL, 다른 앱 이름, 키 입력, 알림 내용, 브라우저 저장 토큰을 넣지 않습니다. 해당 기능은 기본 비활성 상태이며, 운영 전에는 안내·동의·보존 정책이 필요합니다.

## 문제 해결

### 로그인할 수 없음

- 사용자용 주소가 `https://app.5a-math.com/app`인지 확인합니다.
- 동명이인이면 이름+1234가 아니라 관리자에게 받은 6자리 코드를 사용합니다.
- `자격 증명 변경 필요`가 표시되면 새 로그인 ID와 비밀번호를 먼저 설정합니다.
- 세션 만료·로그아웃 후에는 다시 로그인합니다.

### 알림이 오지 않음

- 홈 화면에서 설치된 앱으로 열었는지 확인합니다.
- OS 설정과 브라우저 설정에서 사이트 알림 권한을 허용합니다.
- 앱의 알림 범주 설정을 확인합니다.
- 절전·방해금지 모드가 사이트 알림을 차단하지 않는지 확인합니다.

### 화면이 오래되었거나 모바일 비율이 이상함

1. 앱을 완전히 닫고 홈 화면 아이콘으로 다시 엽니다.
2. 브라우저에서 `/app`을 새로고침합니다.
3. 이전에 `/student-app.html`로 설치한 아이콘이 있다면 제거하고 `/app`에서 다시 설치합니다.
4. 계속되면 사용 중인 기기·OS·브라우저 버전과 화면 캡처를 관리자에게 전달합니다.

### 영상·시험이 잠겨 있음

학생 세션, 공개 대상, 학원 네트워크 여부가 모두 확인됩니다. 외부망에서 정답·영상·시험이 잠기는 것은 의도된 보호 동작이며, 관리자에게 네트워크 정책 확인을 요청합니다.

## 빠른 시작 체크리스트

로컬 개발 계정 하나로 관리자와 학생 역할을 함께 검증할 때는 [로컬 관리자·학생 이중 역할 사용자 테스트 튜토리얼](local-dual-role-user-test-guide.md)을 따른다.

- [ ] `/app` 주소로 접속
- [ ] 개인 학생 계정으로 로그인
- [ ] 필요한 경우 6자리 인증코드 입력
- [ ] 자격 증명 변경 완료
- [ ] Android/iOS/데스크톱에서 홈 화면 또는 앱 설치
- [ ] 공지·영상·숙제·진도 화면 확인
- [ ] 알림 권한과 알림 범주 확인
- [ ] 로그아웃 후 재로그인으로 세션 동작 확인

관리자 문의 시 비밀번호·쿠키·CSRF 토큰·푸시 endpoint를 보내지 말고, 발생한 화면과 기기/브라우저 정보만 전달합니다.
