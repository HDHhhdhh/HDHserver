# 역사 문서 보관소

이 폴더의 문서는 작성 당시의 상태와 판단을 보존한다. 현재 동작이나
의도된 규칙을 판정할 때는 [Server Rules Index](../SERVER_RULES_INDEX.md)와
그 색인이 가리키는 현재 정본을 사용한다.

| 문서 | 보존 목적 |
|---|---|
| `CHATGPT_PROJECT_CONTEXT_2026-08-13.md` | 2026-08-13 ChatGPT 전달용 전체 컨텍스트 |
| `CODEX-HANDOFF_2026-08-13.md` | 2026-08-13 배포·운영 인수인계 |
| `DELTA_NOTES_THROUGH_2026-08-23.md` | 2025~2026 변경 기록 |
| `REFACTOR_NOTES_LOGS_PROGRESS_LEGACY.md` | 로그·진도 리팩터 단계별 계약과 회고 |

역사 문서의 고유 정보는 삭제하지 않는다. 현행 계약으로 승격할 내용은
현재 정본에 먼저 반영한 뒤 이 문서에는 손대지 않는다.
