 - P01~P21 및 P23은 데이터가 맞으면 일반 graph에서 접근 가능하다. P21은 shell/OFF 안내가
   접근 가능하다는 의미이며 집중 원시/활성 수업 데이터 pass가 아니다.
 - P22 OCR은 capabilities가 true일 때만 opener가 나타난다. P24 .showProg는 현재 renderer가 만들지 않는다.
   P25 shared 기록 UI flag false, P26 admin 요일 modal의 current opener 미발견이다.
 - #vidSavePopup은 role=status 성공 feedback이며 독립 입력 popup으로 집계하지 않았다.
   #studentPopupScrim/#studentPopupMobileNav는 공유 backdrop/navigation이므로 별도 dialog 수에 넣지 않았다.
 - hidden #logLegacyWorkspace/#logNotes/#logProgress, #testAppendNotes는 호환 hook이다.
   숙제 #hwWrap/action DOM은 tooltip으로 이동하므로 hidden ancestor 문구만 보고 숙제 전체를 latent로 분류하지 않았다.
 - 오늘 가나다 legacy #todayAlphaSortBtn은 현재 search가 생성되면 제거된다(TO:503~508).
   현재 표의 drag 순서와 /students #stuSort를 이 retired toggle로 혼동하지 않는다.
 - native confirm/prompt/alert는 해당 기능군의 취소/오류 경로에 포함하며 별도 custom popup 정의로 세지 않는다.
